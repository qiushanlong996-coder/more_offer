# 产品设计

## 目标

More Offer 面向软件工程师求职者，帮助用户围绕目标岗位快速完成三件事：

1. 搜索并整理牛客网岗位相关面经。
2. 汇总对应方向的高频力扣题。
3. 形成可复习、可追踪的面试准备清单。

## 核心用户路径

1. 用户输入岗位、公司、技术关键词。
2. 前端请求后端搜索接口。
3. 后端调用牛客面经专属 MCP server 获取候选面经。
4. 后端对结果做清洗、去重、排序和结构化。
5. 前端展示面经摘要、标签、来源链接和匹配原因。
6. 用户切换到力扣高频题视图，按岗位方向查看题目。

## 首屏信息架构

- 顶部：项目名称、搜索入口、数据来源状态。
- 左侧或顶部筛选区：岗位、公司、关键词、页码和数量。
- 主区：面经结果列表，每条展示标题、作者、发布时间、标签、匹配片段、来源。
- 侧区：高频力扣题、准备进度、最近搜索。

移动端采用单列布局，搜索条件折叠为顶部表单，面经和题目使用分段控件切换。

## 非目标

- 不直接复制或长期存储牛客网页全文。
- 不在前端直接访问牛客网。
- 不把第三方站点账号、Cookie、密码写入仓库。
